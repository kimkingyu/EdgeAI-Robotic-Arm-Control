# 香橙派 5 Pro (RK3588S) 连接 PCA9685 舵机板 4 步极简接线指南

> 明天拿起硬件后，照着这个引脚图接 4 根杜邦线，1 分钟搞定硬件连接！

---

## 一、 4 根核心控制线对照表 (母对母杜邦线)

香橙派 5 Pro 的 **40-Pin 扩展引脚**：

| 香橙派 5 Pro 物理引脚编号 | 香橙派功能定义 | 连接到 ➔ | PCA9685 驱动板侧引脚 | 线缆颜色建议 |
| :---: | :---: | :---: | :---: | :---: |
| **Pin 3** | **I2C7_SDA** | ➔ | **SDA** | 绿线 / 蓝线 |
| **Pin 5** | **I2C7_SCL** | ➔ | **SCL** | 黄线 / 白线 |
| **Pin 2** (或 Pin 4) | **5V 电源** (逻辑供电) | ➔ | **VCC** (芯片逻辑电) | 红线 |
| **Pin 6** (或 Pin 9/14) | **GND 地线** | ➔ | **GND** | 黑线 |

> ⚠️ **新手最容易犯的错误（特别注意）**：
> 1. 上面的 **VCC** 只是给 PCA9685 芯片本身供电（几毫安）；
> 2. **绿色的螺丝大接线端子（V+ / GND）**：那是给舵机电机供电的！必须外接独立的 **5V 3A~5A 电池或电源适配器**，千万不要直接用板子的 5V 去带 4 个舵机，舵机一动就会拉低电压导致板子重启！

---

## 二、 机械臂舵机插线顺序 (三色插头)

舵机插头上通常有三根线：**棕色（地线）、红色（正极 5V）、黄色/橙色（PWM 信号）**。
插在 PCA9685 的排针上时，**黄色信号线朝向芯片内侧（PWM 标号端），棕色地线朝向板边（黑色标号端）**：

* **通道 0 (Channel 0)**：插 **底座旋转舵机 (Base Yaw)**
* **通道 1 (Channel 1)**：插 **大臂俯仰舵机 (Shoulder)**
* **通道 2 (Channel 2)**：插 **小臂俯仰舵机 (Elbow)**
* **通道 3 (Channel 3)**：插 **手腕俯仰舵机 (Wrist)**
* **通道 6 (Channel 6)**：插 **末端夹爪开合舵机 (Gripper)**

## 三、 明天开机后的一键检测命令

接好线后，在板端终端直接敲：

```bash
# 1. 扫描 I2C 硬件地址 (看 0x40 是否点亮)
sudo i2cdetect -y 7

# 2. 运行单轴转动与标定测试
python3 -c "from src.controller.i2c_arm import I2CArmController; arm = I2CArmController(bus_num=7, address=0x40); arm.connect(); arm.move_joints([0, 45, 90, 0])"
```
只要看到打印出地址 `40`，机械臂轻轻转动，硬件就彻底活过来了！
