# EdgeAI-Robotic-Arm-Control 研发里程碑与规划路线图 (Project Roadmap)

## 📍 阶段 1：视觉感知与算子硬件亲和力对比实验【进行中 🚀】
- [ ] **1.1 算子兼容性评估与模型导出**：
  - 导出标准的静态 ONNX 计算图（YOLOv8n vs YOLOv11n）。
  - 分析 Attention 结构（C3k2 / C2f）在 RK3588 NPU 上的算子直通率，杜绝算子回退 CPU。
- [ ] **1.2 INT8 离线非对称量化 (PTQ)**：
  - 构建包含典型工业工况（不同光照/阴影/工件表面反光）的 100 张校准数据集。
  - 对比 **Min-Max** 与 **KL 散度** 两种校准算法的量化精度损失（目标 mAP@0.5 损失 < 0.6%）。
- [ ] **1.3 RK3588 3核 NPU 并发推理实测**：
  - 板端运行 `export_rknn.py` 并在 `rknn_engine.py` 中调度 `NPU_CORE_0_1_2`。
  - 输出单核（FP16/INT8）与三核并发下的单帧推理耗时与 FPS 基准对比表。

## 📍 阶段 2：端侧大语言模型 (Qwen) 与端云混合协同【架构就绪 🧠】
- [ ] **2.1 Qwen2.5 W4A16 极限压缩实战**：
  - 在 PC 端运行 `tools/export_rkllm.py`，将 Qwen2.5 模型压缩为板端 `.rkllm` 格式。
  - 将权重显存占用由 1.5GB 压缩至 420MB（压缩比 70%+）。
- [ ] **2.2 工业指令解析与 Function Calling 规划器**：
  - 板端实跑 `src/llm/planner.py`，将复杂自然语言工况指令实时拆解为结构化原子动作序列。
  - 验证离线状态下的安全防撞与规则兜底机制。
- [ ] **2.3 端云协同动态分发与回退评测**：
  - 运行 `tools/compare_cloud_edge.py`，实测云端大模型 API（Qwen-Plus）与端侧 Qwen 在不同网络环境下的首字时延（TTFT）、吞吐率与数据隔离性。
